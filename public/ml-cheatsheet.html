Part 1 Foundations

NumPy Fundamentals

Practice ↗
Broadcasting: align shapes from the right; each pair of dims must be equal or 1.
(N,D) + (D,) → (N,D) · (N,1) * (1,M) → (N,M) · (N,D) + (N,) → error
Reductions: axis=k removes dim k. X.sum(0) → per column (D,) · X.sum(1) → per row (N,)
np.zeros((3, 4)); np.eye(3); np.full(5, 7.)
np.arange(0, 10, 2)    # [0 2 4 6 8]
np.linspace(0, 1, 5)   # 5 pts, both ends
x[1:4]; x[::-1]; x[x > 0]; x[[0, 2]]
X[:, None]             # (N,) -> (N, 1)
X.reshape(2, -1); X.T; X.swapaxes(-1, -2)
X - X.mean(0, keepdims=True) # center cols
X.argmax(axis=1)       # index per row

Slices are views: writing to x[1:4] changes x. Boolean and fancy indexing return copies. ravel() may be a view, flatten() always copies. reshape never transposes: (2,3).reshape(3,2) keeps row-major order.

Python Basics for ML

Practice ↗
A @ B: (m,k) @ (k,n) → (m,n), m·k·n multiply-adds
batched: (…,m,k) @ (…,k,n) → (…,m,n) · * is elementwise
np.sum(X)          # not builtin sum() on 2-D
A @ B              # == np.matmul(A, B)
np.dot(u, v)       # 1-D: inner product
np.outer(u, v)     # (m,), (n,) -> (m, n)
X + b              # (N,D) + (D,): per column
X + c[:, None]     # (N,D) + (N,1): per row

(N,) vs (N,1): y_pred - y with shapes (N,1) and (N,) silently broadcasts to (N,N) and the loss is wrong but finite. Assert shapes before you reduce. A Python loop over elements is ~100× slower than the vectorized call.

Einstein Summation

Practice ↗
Indices in the inputs but not after -> are summed; the output follows the order you write.
PatternMeaningPatternMeaning
ij->sumik,kj->ijmatmul
ij->jcolumn sumsi,i->dot
ij->jitransposei,j->ijouter
ii->idiagonalij,ij->Frobenius ⟨A,B⟩
ii->tracebij,bjk->bikbatched matmul
# attention scores and output, (B,h,T,dk)
S = np.einsum('bhqd,bhkd->bhqk', Q, K)
O = np.einsum('bhqk,bhkd->bhqd', A, V)

Without -> (implicit mode) the output indices are sorted alphabetically, so einsum('ji', A) is A.T. Always write the arrow. For 3+ operands pass optimize=True.

F.cross_entropy wants raw logits (N,C) and int64 class indices (N,): applying softmax first trains on the wrong loss. .grad accumulates until you zero it. Forgetting model.eval() leaves dropout and BatchNorm in training mode. view needs contiguous memory; reshape copies when it must.

Part 2 Classical ML

Data Preprocessing

Practice ↗
Min-max: (X − min₀) / (max₀ − min₀) → [0, 1] per column
Z-score: (X − μ₀) / σ₀, per column, σ with ddof = 0
One-hot: np.eye(C)[y] → (N, C)
Stratified split: per class, shuffle, put round(frac·n_c) in test
mu, sd = X_tr.mean(0), X_tr.std(0)
sd = np.where(sd == 0, 1.0, sd) # const col
X_tr = (X_tr - mu) / sd
X_te = (X_te - mu) / sd          # TRAIN stats
fill = np.nanmean(X_tr, axis=0)
X = np.where(np.isnan(X), fill, X)

Leakage: fitting the scaler, imputer or feature selection on all data (or on the test fold) before splitting inflates every metric. Fit on train, transform the rest. X.mean() with no axis normalizes everything by one global number.

Supervised Learning

Practice ↗

Linear models

ŷ = Xw + b · MSE = (1/N)Σ(ŷ − y)²
∇w = (2/N)·Xᵀ(ŷ − y) · ∇b = (2/N)·Σ(ŷ − y)
Ridge: w = (XᵀX + λI)⁻¹Xᵀy (don't penalize b)
Lasso step: soft(z, λ) = sign(z)·max(|z| − λ, 0)
Logistic: p = σ(Xw + b) · BCE = −(1/N)Σ[y log p + (1−y) log(1−p)]
∇w = (1/N)·Xᵀ(p − y) (same form as MSE, no factor 2)
Hinge (y ∈ {−1,+1}): mean max(0, 1 − y·f(x)) + λ‖w‖²

Trees, neighbours, ensembles

Gini = 1 − Σp_k² · Entropy = −Σp_k log₂ p_k
Gain = H(parent) − Σ (n_c/n)·H(child_c)
kNN: ‖a−b‖² = ‖a‖² + ‖b‖² − 2a·b, vote of the k nearest
Gaussian NB: argmax_c log π_c + Σ_j log N(x_j; μ_cj, σ²_cj)
Boosting (MSE): F₀ = ȳ; fit h_m to r = y − F_{m−1}; F_m = F_{m−1} + ν·h_m
Bagging: bootstrap N rows with replacement (≈63.2% unique), average or vote
# work from logits z: stable for any z
p   = np.exp(-np.logaddexp(0, -z))  # σ(z)
bce = np.mean(np.logaddexp(0, z) - y * z)
w = np.linalg.solve(X.T @ X + lam * np.eye(D),
                    X.T @ y)

1/(1+np.exp(-z)) overflows for very negative z and log(0) = -inf blows up BCE: use the logit form (PyTorch: F.binary_cross_entropy_with_logits). Hinge needs labels ±1, BCE needs 0/1. Use solve, never inv.

Unsupervised Learning

Practice ↗
k-means: J = Σᵢ‖xᵢ − μ_{cᵢ}‖²; assign → argmin, update → cluster mean
k-means++: next center sampled ∝ D(x)², distance to nearest chosen center
PCA: X_c = X − mean = U S Vᵀ; components = Vᵀ[:k]; var ratio = S²/ΣS²
GMM E-step: γ_ik = π_k N(xᵢ|μ_k,Σ_k) / Σ_j π_j N(xᵢ|μ_j,Σ_j)
M-step: N_k = Σᵢγ_ik, π_k = N_k/N, μ_k = Σᵢγ_ik xᵢ / N_k, Σ_k = Σᵢγ_ik (xᵢ−μ_k)(xᵢ−μ_k)ᵀ / N_k
DBSCAN: core if |N_ε(x)| ≥ minPts (x included); grow clusters from cores; border = within ε of a core; rest = noise (−1)
d2 = ((X[:, None] - C[None]) ** 2).sum(-1)
labels = d2.argmin(1)               # (N,)
C = np.stack([X[labels == k].mean(0)
              if (labels == k).any() else C[k]
              for k in range(K)])
Xc = X - X.mean(0)
U, S, Vt = np.linalg.svd(Xc,
                          full_matrices=False)
Z = Xc @ Vt[:k].T                   # (N, k)

An empty cluster averages nothing and returns NaN. PCA without centering finds the mean, not the variance. np.linalg.eigh sorts eigenvalues ascending, and eigenvector signs are arbitrary (compare up to ±). Run GMM in log space with logsumexp and add εI to Σ.

Model Evaluation

Practice ↗
Precision = TP/(TP+FP) · Recall = TPR = TP/(TP+FN)
FPR = FP/(FP+TN) · Accuracy = (TP+TN)/N
F1 = 2PR/(P+R) · F_β = (1+β²)PR/(β²P + R)
ROC AUC = P(s⁺ > s⁻) + ½P(s⁺ = s⁻); 0.5 = random
AP = Σ_n (R_n − R_{n−1})·P_n over thresholds
ECE = Σ_m (|B_m|/N)·|acc(B_m) − conf(B_m)|, equal-width bins
R² = 1 − SS_res/SS_tot · MAE = mean|y − ŷ|
# rows = true class, cols = predicted
cm = np.bincount(C * y + yhat, minlength=C * C
                 ).reshape(C, C)
pos, neg = s[y == 1], s[y == 0]
gt = (pos[:, None] > neg).mean()
auc = gt + 0.5 * (pos[:, None] == neg).mean()

Accuracy hides imbalance: with 99% negatives, "always 0" scores 99%. Report PR-AUC, recall at fixed precision or F1. Guard 0/0 when nothing is predicted positive. Tune thresholds on validation, never test, and split CV folds by user/patient when rows are correlated.

Every gradient has the shape of what it differentiates: if dW.shape != W.shape, a transpose is wrong. The bias gradient sums over the batch. A perceptron never converges on non-separable data (XOR).

Neural Networks

Practice ↗
softmax(z)ᵢ = e^(zᵢ − max z) / Σⱼ e^(zⱼ − max z)
CE = −(1/N)Σᵢ log p_{i,yᵢ}; ≈ ln C at init
softmax + CE (mean): dZ = (P − Y)/N
Xavier: Var(W) = 2/(fan_in + fan_out); uniform ±√(6/(fan_in + fan_out))
He (ReLU): Var(W) = 2/fan_in → std = √(2/fan_in)
BatchNorm: x̂ = (x − μ_B)/√(σ²_B + ε), y = γx̂ + β; running ← (1−m)·running + m·batch (m = 0.1)
Inverted dropout: y = x ⊙ mask/(1−p), mask ~ Bernoulli(1−p); eval: y = x
def softmax(z, axis=-1):
    e = np.exp(z - z.max(axis, keepdims=True))
    return e / e.sum(axis, keepdims=True)
def log_softmax(z):
    z = z - z.max(-1, keepdims=True)
    s = np.exp(z).sum(-1, keepdims=True)
    return z - np.log(s)
loss = -log_softmax(Z)[np.arange(N), y].mean()
dZ = softmax(Z)
dZ[np.arange(N), y] -= 1; dZ /= N

np.log(softmax(z)) underflows to -inf; use log-softmax. Forgetting /N in dZ when the loss is a mean makes gradients N× too large. In masked CE, average over real tokens only (ignore_index=-100), not over all positions.

Optimization & Training

Practice ↗
SGD: θ −= lr·g · Momentum: v = μv + g; θ −= lr·v
RMSprop: s = ρs + (1−ρ)g²; θ −= lr·g/(√s + ε)
Adam: m = β₁m + (1−β₁)g; s = β₂s + (1−β₂)g²
m̂ = m/(1−β₁ᵗ), ŝ = s/(1−β₂ᵗ); θ −= lr·m̂/(√ŝ + ε) (t starts at 1)
AdamW: also θ −= lr·λ·θ, decoupled from the gradient
Global-norm clip: n = √(Σ‖gᵢ‖²); if n > c: gᵢ *= c/(n + 1e-6)
Loss scaling: overflow → skip step, S *= 0.5, reset counter; 2000 clean steps in a row → S *= 2
Grad accumulation: loss/k on each of k micro-batches, one step
scaler.scale(loss).backward()
scaler.unscale_(opt)              # true grads
torch.nn.utils.clip_grad_norm_(
    model.parameters(), max_norm=1.0)
scaler.step(opt); scaler.update()
opt.zero_grad()

Check: grads [3, 4] and [12], c = 1 → n = 13, both scaled by 1/13. Adam's first step is ≈ lr whatever the gradient scale.

Clipping the scaled gradients compares max_norm with S × the true norm: unscale first. Clipping each tensor separately changes the direction. An L2 term in the loss is not weight decay under Adam (use AdamW). Adam keeps 2 extra tensors per parameter.

def iou(a, b):
    lt = np.maximum(a[:2], b[:2])  # top-left
    rb = np.minimum(a[2:], b[2:])  # bottom-rt
    inter = np.prod(np.clip(rb - lt, 0, None))
    area = lambda z: (z[2]-z[0]) * (z[3]-z[1])
    return inter / (area(a) + area(b) - inter)

             if iou(B[i], B[j]) <= thr]

Check: 224 → conv 7×7 s2 p3 → 112 → pool 3×3 s2 p1 → 56. 3×3 conv 64→128 = 73,728 weights.

Sequence Models

Practice ↗
RNN: h_t = tanh(x_t W_xh + h_{t−1} W_hh + b) x_t: (N,D), h: (N,H)
LSTM gates = xW_ihᵀ + b_ih + hW_hhᵀ + b_hh, split i, f, g, o
c′ = σ(f)⊙c + σ(i)⊙tanh(g) · h′ = σ(o)⊙tanh(c′)
GRU (PyTorch, split r, z, n): r, z = σ(·); n = tanh(xW_inᵀ + b_in + r⊙(hW_hnᵀ + b_hn))
h′ = (1 − z)⊙n + z⊙h (z = 1 keeps h)
Params: RNN DH + H² + H · LSTM 4(HD + H² + 2H) · GRU 3(HD + H² + 2H)
BPTT: ∂h_T/∂h_1 = Π_t diag(1 − h_t²)·W_hhᵀ → vanishes or explodes
z = x @ W_ih.T + b_ih + h @ W_hh.T + b_hh
i, f, g, o = np.split(z, 4, axis=1)
c = sigmoid(f) * c + sigmoid(i) * np.tanh(g)
h = sigmoid(o) * np.tanh(c)

Gate order runs without error and gives wrong numbers: PyTorch is i,f,g,o (LSTM) and r,z,n (GRU), and the GRU reset gate multiplies after the hidden matmul. nn.RNN is (T,N,D) unless batch_first=True. Clipping fixes exploding, not vanishing, gradients.

Part 4 Transformers & LLMs

Transformer Architecture

Practice ↗
Attn(Q,K,V) = softmax(QKᵀ/√d_k + M)·V, M_ij = −∞ for j > i (causal)
MHA: (B,T,D) → (B,T,h,d_k) → (B,h,T,d_k); attend; merge; @ W_O
Sinusoidal: PE[p,2i] = sin(p/10000^(2i/D)), PE[p,2i+1] = cos(…)
RoPE: θᵢ = 10000^(−2i/d); rotate pair (x₂ᵢ, x₂ᵢ₊₁) by p·θᵢ → q_m·k_n depends on m − n
LayerNorm: γ(x − μ)/√(σ² + ε) + β over the last dim, biased σ²
Pre-norm: x += Attn(LN(x)); x += FFN(LN(x)) (2017 paper: post-norm x = LN(x + f(x)))
GQA: h_q query heads share h_kv K/V heads; np.repeat each KV head h_q/h_kv times
Sliding window: j visible iff 0 ≤ i − j < W → O(T·W)
Backward: dV = AᵀdO · dA = dO Vᵀ · dS = A ⊙ (dA − rowsum(dA ⊙ A)) · dQ = dS K/√d_k · dK = dSᵀQ/√d_k
Cost: O(T²·d) time, O(T²) memory per head · block ≈ 12D² params
def attention(Q, K, V, causal=False):
    d_k = Q.shape[-1]
    S = Q @ K.swapaxes(-1, -2) / np.sqrt(d_k)
    if causal:
        T = S.shape[-1]
        fut = np.triu(np.ones((T,T), bool), 1)
        S = np.where(fut, -np.inf, S)
    A = softmax(S, axis=-1)
    return A @ V, A
# (B,T,D) -> (B,T,h,dk) -> (B,h,T,dk)
xh = x.reshape(B, T, h, dk).transpose(0,2,1,3)
F.scaled_dot_product_attention(
    q, k, v, is_causal=True)   # (B,h,T,dk)

Reshaping straight to (B,h,T,d_k) mixes tokens across heads: reshape, then transpose. Scale by √d_k per head, not √D. On a 4-D NumPy array K.T reverses all axes and K.transpose(-2,-1) is an error (that is PyTorch syntax): use swapaxes(-1,-2). A fully masked row gives NaN.

LLM Generation & Decoding

Practice ↗
Temperature: p = softmax(z/T); T < 1 sharper, ranking unchanged
Top-k: keep the k largest logits, rest −∞, softmax
Top-p: sort desc, keep the smallest prefix with cumsum ≥ p (include the crossing token)
Repetition penalty θ, each distinct generated token: z/θ if z > 0 else z·θ
Beam: score = Σ log p, keep B best; compare finished beams by score/len^α
KV cache = 2·L·h_kv·d_head·T·bytes per sequence
Speculative: accept draft x w.p. min(1, p(x)/q(x)); on reject sample norm(max(0, p − q)); all K accepted → bonus token from p
def top_p_filter(z, p):
    probs = softmax(z)
    order = np.argsort(-probs, kind='stable')
    csum = np.cumsum(probs[order])
    n = np.searchsorted(csum, p) + 1  # keep n
    out = np.full_like(z, -np.inf)
    out[order[:n]] = z[order[:n]]
    return softmax(out)

Check: z = [2, 1, 0.1] → T=1: [0.659, 0.242, 0.099]; T=0.5: [0.864, 0.117, 0.019]; top-p 0.8 keeps 2 tokens. LLaMA-2-7B (L=32, h_kv=32, d_head=128) at 4k tokens in fp16: 2 GiB of KV cache.

Temperature first, then filter logits to -inf and softmax (or renormalize). Dividing a negative logit by the penalty makes the token more likely. Beam search must add log-probs; multiplying probabilities underflows. Decoding is memory-bandwidth-bound, not FLOP-bound.

LLM Internals

Practice ↗
RMSNorm(x) = x/√(mean(x²) + ε)·w (no mean, no bias)
SwiGLU FFN = (SiLU(xW_gate) ⊙ xW_up)·W_down; d_ff ≈ (8/3)D keeps ≈ 8D² params
Online softmax per block S_b: m′ = max(m, max S_b)
l = l·e^(m−m′) + Σe^(S_b−m′) · acc = acc·e^(m−m′) + e^(S_b−m′)·V_b · out = acc/l
MoE: g = softmax(top-k router logits); y = Σⱼ gⱼ·E_{iⱼ}(x)
Load balance: aux = E·Σ_e f_e·P_e (f: fraction routed, P: mean router prob)
Perplexity = exp(−(1/N)Σ_t log p(x_t | x_<t)), N = real tokens; uniform over V → V
def rmsnorm(x, w, eps=1e-6):
    ms = (x * x).mean(-1, keepdims=True)
    return x / np.sqrt(ms + eps) * w
silu = lambda z: z / (1 + np.exp(-z))
n = rmsnorm(x, w)
x = x + (silu(n @ Wg) * (n @ Wu)) @ Wd
m, l = -np.inf, 0.0          # online sm
for b in blocks:
    m2 = max(m, b.max())
    l = l*np.exp(m-m2) + np.exp(b - m2).sum()
    m = m2

Check: [0, 1, 5, 2, 9] in blocks of 2 → l = 1.3679, 1.0748, 1.0197. Mixtral 8×7B: ≈47B total, ≈13B active (top-2).

When the max changes, rescale acc as well as l, and divide by l only at the end. Perplexity divides by real tokens (mask padding) and is only comparable under the same tokenizer. MoE: f comes from routing counts, P from the full (not top-k) softmax.

Representation Learning & Retrieval

Practice ↗
cos(a, b) = a·b/(‖a‖‖b‖); all pairs: Q̂ D̂ᵀ with rows L2-normalized

Normalize rows (axis=1), not columns. argsort(s)[::-1] reverses ties; sort -s stably. Raw BM25 is unbounded and cosine is in [−1, 1]: normalize before fusing. Small τ overflows without max-subtraction.

def gae(r, v, done, g=0.99, lam=0.95):
    # len(v) = len(r) + 1 (bootstrap value)
    A, last = np.zeros(len(r)), 0.0
    for t in reversed(range(len(r))):
        nd = 1.0 - done[t]
        d = r[t] + g * v[t + 1] * nd - v[t]
        A[t] = last = d + g * lam * nd * last
    return A        # returns = A + v[:-1]

Sanity checks before you trust a model

  • Loss at init ≈ ln C (10 classes: 2.303; GPT-2 vocab: 10.82).
  • It can overfit one small batch to ≈ 0 loss.
  • Shapes printed at every layer of the first forward pass.

Bug-hunt checklist

  • Causal mask missing (loss suspiciously low) or masking the diagonal.
  • Scale √D instead of √d_k; softmax over the wrong axis.
  • Targets not shifted by one, so the model learns to copy.
  • Residual dropped, dropout left on in eval, LayerNorm over the batch axis.

The capstones reuse every earlier block: when one fails, unit-test the piece (attention, LayerNorm, the loss) against its section before debugging the whole model.
