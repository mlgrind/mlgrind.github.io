Common Loss Functions

Implement loss functions used in deep learning.

Cross-Entropy Loss

L = -sum(y * log(softmax(logits)))

MSE Loss

L = mean((y_pred - y_true)²)

Binary Cross-Entropy

L = -mean(y * log(p) + (1-y) * log(1-p))
