Linear Regression with Gradient Descent

Implement simple linear regression using gradient descent optimization.

Model

y = w * x + b

Gradient Descent Updates

w = w - learning_rate * dw
b = b - learning_rate * db

Where:

  • dw = (2/n) * sum((y_pred - y) * x)
  • db = (2/n) * sum(y_pred - y)
