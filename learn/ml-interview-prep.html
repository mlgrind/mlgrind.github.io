ML coding interview prep

The problems that come up most in ML coding interviews: stable losses, classic models, evaluation metrics, a neural network by hand and attention. Each fits in an interview slot, and the hidden tests check the edge cases interviewers ask about.

11 problems · about 4 h · Intermediate. You'll need: Comfortable with NumPy; basic calculus and linear algebra.

By the end you can

  • Implement the classic algorithms from a blank file, each in under 40 minutes
  • Derive and explain the gradients you code, as interviewers ask you to
  • Handle numerical stability, ties and zero-division cases without prompting

Steps

  1. Step 1: Numerically Stable Softmax → Softmax without overflow, often the first thing an interviewer checks.
  2. Step 2: Cross-Entropy Loss → Cross-entropy from logits, and why you never take the log of a softmax.
  3. Step 3: Linear Regression with Gradient Descent → Gradient descent end to end: loss, gradient, update, convergence.
  4. Step 4: Logistic Regression with Gradient Descent → Logistic regression with the gradient derived by hand.
  5. Step 5: k-Nearest Neighbours Classifier → Vectorised pairwise distances and deterministic tie-breaking.
  6. Step 6: K-Means from Scratch (k-means++ Init, Convergence, Empty Clusters) → K-means with k-means++ initialisation and empty clusters handled.
  7. Step 7: Gini Impurity for Decision-Tree Splits → Gini impurity, the score a tree uses to pick its splits.
  8. Step 8: Precision and Recall → Precision, recall and F1, including the zero-division cases.
  9. Step 9: ROC Curve & AUC (with Ties) → ROC AUC with tied scores, a common follow-up question.
  10. Step 10: MLP Forward & Backward Pass → A two-layer network's forward and backward pass by hand.
  11. Step 11: Scaled Dot-Product Attention → Attention, now standard in interviews for LLM roles.
